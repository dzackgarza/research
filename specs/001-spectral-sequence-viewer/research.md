# Design decisions

| Decision | Reason | Alternative considered |
| --- | --- | --- |
| Use the proposed TypeScript custom element with one registration module. | A static page, a dynamically inserted element, and a React ref can all assign the same object property. | A React component as the public API would require a separate static mount interface. |
| Build an ES library with Vite in its own package. | Plain HTML can import the distributed module directly. The root repository is a research and Quarto workspace. | Coupling the module to the book build would make a second site's deployment depend on Quarto. |
| Use SVG for axes and arrows and focusable HTML controls for cells, placed from the same coordinate layout. | Blank cells retain keyboard targets, and TeX labels can use normal HTML math containers. | A canvas would need separate hit testing and an accessible interaction surface. |
| Package MathJax and its required assets with the distribution. Scope conversion to each figure and discard obsolete asynchronous results. | Static hosts can serve the complete figure. Rapid page changes and multiple figures must keep their own labels. | Depending on a host MathJax global works for some book pages but adds a prerequisite for independent hosts. |
| Use JSON Schema plus a semantic validation pass. | The schema can describe record shapes and enums. Continuity and incidence require comparisons across records. | A TypeScript type alone cannot validate an article author's JSON. |

The repository's `writing/dependency-graph.md` already updates math in an interactive article. The reusable viewer takes responsibility for its own math lifecycle. See [MathJax dynamic content](https://docs.mathjax.org/en/latest/advanced/typeset.html), [Vite library mode](https://vite.dev/guide/build.html#library-mode), and [React custom elements](https://react.dev/reference/react-dom/components#custom-html-elements).

## What published spectral-sequence charts can express

The comparisons below use Hood Chatham's [SpectralSequences manual](https://mirrors.ctan.org/graphics/pgf/contrib/spectralsequences/manual/spectralsequencesmanual.pdf), especially “The Main Commands” and “Global Options”, and Tilman Bauer's [sseq manual](https://mirrors.ctan.org/macros/latex/contrib/sseq/sseq.pdf), especially its placement, naming, and clipping commands. Bauer's [luasseq manual](https://mirrors.ctan.org/macros/luatex/latex/luasseq/luasseq.pdf) also documents named objects within a grid square. The implementation compared is research revision 36588b72cd.

| Author or reader operation | Evidence in the manuals | Current viewer and consequence |
| --- | --- | --- |
| Follow one class among several in the same bidegree | Chatham's class names and tags and Bauer's named symbols give incident edges a specific endpoint within a group of marks. | The chart provides one selectable cell per bidegree. T021 can describe the images of two generators in the inspector, but the diagram still needs to identify which generator a line meets. Linear combinations must remain expressible in the component map. |
| Track a surviving class or subquotient across pages | Chatham's replacement examples show a quotient at the target and a subgroup at the source on the next page. | Authors can enter the next group as a new snapshot. There is no relation identifying its representative or predecessor. A permanence assertion is keyed to the whole bidegree, so it cannot describe one permanent summand while another supports a differential there. |
| Read multiplication and extension data | Chatham distinguishes structure lines, with specified class endpoints and page visibility, from extensions displayed at infinity. | Every edge in the model is a differential. An author cannot encode multiplication by a fixed class as its own relation or supply a known hidden extension. Equal associated graded groups alone cannot determine the extension. |
| Trace a map across the chart boundary | Bauer clips a drawn line at the viewport. Chatham also considers edges crossing the viewport with both endpoints outside it. | The plot iterates over visible sources and draws a line only if its target is visible. Even a known nonzero map can leave no trace on the plot. The inspector recovers the other endpoint only if a reader can select an incident cell. |
| Read an Adams chart in stem and filtration | Chatham supplies an Adams grading and allows a page-dependent differential degree. | T020 already separates display and native coordinates. A second acceptance example should use stem and filtration, where an Adams differential moves one stem left and raises filtration by the page index. A projection changes positions; a custom native differential degree changes incidence. |
| Compare differentials from several pages or follow a named family | Chatham's page-range view overlays differentials from a chosen interval on an identified base page. Families group classes and lines for display. Bauer also supports disjoint coordinate ranges. | The current viewer shows one contiguous rectangle on one page. An overlay, a family filter, and an axis break are distinct optional reading aids. An overlay must retain the page of each map. |

The first four rows affect which mathematical facts a chart can communicate. The last two distinguish grading coverage from optional presentation features. Package support is evidence of a use case, not a requirement to implement a TeX interpreter or to infer algebra from the drawing.
