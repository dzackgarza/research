# Edit-specific reading index

Use this index before editing. Read the linked sections, then follow any rule or
owner they invoke. The index limits initial reading; it does not waive a rule.
For work in `lattice-database`, read its own `AGENTS.md`, `CONTRIBUTING.md`, and
the relevant local issue and source instructions as well.

## Every edit

1. Read [the architecture mandate](../INTENT.md#intent-the-architecture-of-lean-categories-lean-cas-dsl-and-their-leaves) and [governing correction](../INTENT.md#governing-correction-2026-10-13-categorical-framing-and-augmented-resolutions), [the silo contracts](../INTENT.md#the-contracts-between-silos), [core invariants](../INTENT.md#core-invariants), [trust boundaries](../INTENT.md#trust-boundaries), and [prohibited states](../INTENT.md#what-must-be-impossible). Read the earlier discussion when it supplies context needed for the edit; later corrections govern.
2. Read the [evidence model](../AGENTS.md#the-evidence-model-nothing-from-a-leaf-is-trusted-read-before-anything-else), [mathematical acceptance](../AGENTS.md#acceptance-is-mathematics-owner-2026-10-09), [main-line policy](../AGENTS.md#one-line-of-record-originmain-always-on), [architecture-before-tests rule](../AGENTS.md#architecture-before-tests-always-on), [mathematical tracing and complaints](../AGENTS.md#mathematical-tracing-and-complaints-always-on), and [issue execution order](../AGENTS.md#execution-order).
3. Read [delivery](../CONTRIBUTING.md#delivery-workflow), [contribution policy routing](../CONTRIBUTING.md#contribution-policies), and [commit policy](../CONTRIBUTING.md#commit-01-read-the-contributing-policies-before-every-commit). Read the selected issue's full body, dependencies, and relevant comments in the [native issue tree](https://github.com/dzackgarza/research/issues/46). Read [TODO.md](../TODO.md) from its introduction through the selected workstream; search it for the issue number and affected construction.
4. Read the `AGENTS.md` and `README.md` in each subtree being edited, if present. Inspect the live source and relevant consumers before proposing an edit. Revisit this index when the work crosses into another edit type.
