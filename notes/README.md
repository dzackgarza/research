# Notes

Human-readable research notes live here.

## Layout

- `papers/`: notes organized by source paper.

- `topics/`: imported cross-paper findings, speculative threads, and mathematical synthesis.

- `computations/`: notes about computational artifacts, extraction plans, and comparisons.

- `lattice-interface-contract/`: a typed interface contract for lattice operations, designed backend-first; retained as design material, with the automorphism-lifting family the preamble does not own.

- `category-design/`: the design corpora behind the preamble's category tree (its own README indexes them), including the n-category specification tower and the corrected lattice-category roster.

These folders are conveniences for existing material, not required categories.
New notes may start as loose scratch notes and be named after the problem, calculation, or thread when a useful shape emerges.

Agent/operator instructions do not belong here.
Put Sage usage traps, source-discovery guidance, and workflow notes under `.agents/`.
