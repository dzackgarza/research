# Digraph Categories: From Directed Graphs to Free Categories

Every directed graph generates a free category by taking paths as morphisms. This is more general than poset categories and allows multiple morphisms between objects, making it perfect for constructing diagram categories like parallel pairs, walking arrows, and more complex shapes.

---

## Mathematical Foundation

### **Digraph → Free Category Construction**

Given a directed graph G = (V, E), we construct the **free category** F(G) as follows:

- **Objects**: Vertices V of the graph
- **Morphisms**: Paths in the graph (including empty paths as identities)
- **Composition**: Path concatenation
- **Identities**: Empty path at each vertex

### **Key Properties**

1. **Free Construction**: Universal property - any functor from vertices extends uniquely
2. **Path Category**: Morphisms are freely generated by graph edges
3. **Multiple Morphisms**: Can have many morphisms between objects (unlike posets)
4. **No Equations**: Unless we impose relations, all paths are distinct

## Implementation Plan

### **1. Basic Digraph Category Constructor**

```python
class DigraphCategory(Category):
    """
    Free category generated by a directed graph.
    
    Morphisms are paths in the graph, with composition given by
    path concatenation.
    
    EXAMPLES::
    
        sage: # Category from a simple digraph
        sage: G = DiGraph([(0, 1, 'f'), (1, 2, 'g'), (0, 2, 'h')])
        sage: C = DigraphCategory(G)
        sage: C
        Free category on graph with 3 vertices and 3 edges
        
        sage: # Morphisms are paths
        sage: C.hom_set(0, 2)
        {Path(0 --h--> 2), Path(0 --f--> 1 --g--> 2)}
        
        sage: # Composition is path concatenation
        sage: f = C.morphism(0, 1, ['f'])
        sage: g = C.morphism(1, 2, ['g'])
        sage: g * f  # g ∘ f
        Path(0 --f--> 1 --g--> 2)
    """
    
    def __init__(self, digraph):
        """
        INPUT:
        - digraph: A DiGraph object from SageMath
        
        EXAMPLES::
        
            sage: # Parallel pair: two morphisms 0 → 1
            sage: G = DiGraph([(0, 1, 'f'), (0, 1, 'g')])  
            sage: C = DigraphCategory(G)
        """
        self._digraph = digraph
        super().__init__()
    
    def objects(self):
        """Return the objects (vertices of the graph)."""
        return list(self._digraph.vertices())
    
    def hom_set(self, x, y):
        """
        Return all morphisms (paths) from x to y.
        
        This includes:
        - Identity (empty path) if x = y
        - All paths from x to y in the digraph
        """
        if x == y:
            # Identity morphism (empty path)
            paths = [PathMorphism(x, y, [], self)]
        else:
            paths = []
        
        # Add all non-empty paths from x to y
        for path in self._digraph.all_paths(x, y):
            if len(path) > 1:  # Non-trivial path
                edge_labels = []
                for i in range(len(path) - 1):
                    # Get edge label from path[i] to path[i+1]
                    edge = self._digraph.edge_label(path[i], path[i+1])
                    edge_labels.append(edge)
                paths.append(PathMorphism(x, y, edge_labels, self))
        
        return set(paths)
    
    def compose(self, f, g):
        """
        Compose morphisms by concatenating paths.
        
        If f: y → z and g: x → y, then f ∘ g: x → z
        is the concatenated path.
        """
        if f.domain() != g.codomain():
            raise ValueError("Morphisms not composable")
        
        # Concatenate paths
        new_path = g.edges() + f.edges()
        return PathMorphism(g.domain(), f.codomain(), new_path, self)
    
    def identity_morphism(self, x):
        """Return identity morphism (empty path) at x."""
        return PathMorphism(x, x, [], self)
    
    def generators(self):
        """
        Return the generating morphisms (graph edges).
        
        These freely generate all morphisms in the category.
        """
        generators = []
        for edge in self._digraph.edges():
            src, tgt, label = edge
            gen = PathMorphism(src, tgt, [label], self)
            generators.append(gen)
        return generators
    
    def is_free(self):
        """This is always a free category."""
        return True
    
    def relations(self):
        """
        Return relations between paths (none in free category).
        
        Subclasses can override to add equations between paths.
        """
        return []

class PathMorphism:
    """
    A morphism in a digraph category (a path in the graph).
    """
    
    def __init__(self, source, target, edges, category):
        """
        INPUT:
        - source: starting vertex
        - target: ending vertex  
        - edges: list of edge labels forming the path
        - category: the parent DigraphCategory
        """
        self._source = source
        self._target = target
        self._edges = edges
        self._category = category
    
    def domain(self):
        return self._source
    
    def codomain(self):
        return self._target
    
    def edges(self):
        """Return the list of edges in this path."""
        return self._edges
    
    def length(self):
        """Return the length of the path."""
        return len(self._edges)
    
    def is_identity(self):
        """Test if this is an identity (empty path)."""
        return len(self._edges) == 0
    
    def __repr__(self):
        if self.is_identity():
            return f"id_{self._source}"
        else:
            path_str = " --".join([str(e) + "--> " for e in self._edges])
            return f"Path({self._source} --{path_str}{self._target})"
    
    def __eq__(self, other):
        """Paths equal iff same source, target, and edge sequence."""
        return (isinstance(other, PathMorphism) and
                self._source == other._source and
                self._target == other._target and
                self._edges == other._edges)
    
    def __hash__(self):
        return hash((self._source, self._target, tuple(self._edges)))
    
    def __mul__(self, other):
        """Composition via category."""
        return self._category.compose(self, other)
```

### **2. Standard Digraph Constructions**

```python
def parallel_pair_category():
    """
    Category with two parallel morphisms: X ⟹ Y.
    
    This is the indexing category for equalizers and coequalizers.
    
    EXAMPLES::
    
        sage: C = parallel_pair_category()
        sage: C.objects()
        [0, 1]
        sage: C.hom_set(0, 1)
        {Path(0 --f--> 1), Path(0 --g--> 1)}
        sage: # Two distinct morphisms from 0 to 1
    """
    G = DiGraph([(0, 1, 'f'), (0, 1, 'g')])
    return DigraphCategory(G)

def walking_arrow_category():
    """
    The "walking arrow" category: • → •.
    
    Universal category with one non-identity morphism.
    Functors from this category are just morphisms in the target.
    
    EXAMPLES::
    
        sage: C = walking_arrow_category()
        sage: C.objects()
        [0, 1]
        sage: C.hom_set(0, 1)
        {Path(0 --arrow--> 1)}
    """
    G = DiGraph([(0, 1, 'arrow')])
    return DigraphCategory(G)

def walking_isomorphism_category():
    """
    Category with one isomorphism: • ⟷ •.
    
    EXAMPLES::
    
        sage: C = walking_isomorphism_category()
        sage: f = C.morphism(0, 1, ['f'])
        sage: g = C.morphism(1, 0, ['g'])
        sage: f * g  # Should equal identity
        # In free category, this is NOT identity!
        # Need quotient category for true isomorphism
    """
    G = DiGraph([(0, 1, 'f'), (1, 0, 'g')])
    return DigraphCategory(G)
    # Note: To make f,g inverses, need QuotientCategory with relations

def commutative_square_category():
    """
    Commutative square category.
    
        0 --a--> 1
        |        |
        b        c
        |        |
        v        v
        2 --d--> 3
    
    Used for pullback/pushout diagrams.
    """
    G = DiGraph([
        (0, 1, 'a'), (0, 2, 'b'),
        (1, 3, 'c'), (2, 3, 'd')
    ])
    return DigraphCategory(G)
    # Note: Paths a;c and b;d are distinct in free category!

def walking_reflexive_pair_category():
    """
    Reflexive pair: parallel morphisms with common section.
    
        0 ⟹ 1
         ↖s↙
    
    Used for split equalizers and reflexive coequalizers.
    """
    G = DiGraph([
        (0, 1, 'f'), (0, 1, 'g'),  # Parallel pair
        (1, 0, 's')                # Common section
    ])
    return DigraphCategory(G)
```

### **4. Diagram Construction from Digraph Categories**

```python
def parallel_morphisms_diagram(f, g, target_category):
    """
    Create a diagram of parallel morphisms for equalizer/coequalizer.
    
    INPUT:
    - f, g: parallel morphisms X → Y in target_category
    - target_category: where the diagram lives
    
    OUTPUT:
    Diagram indexed by parallel pair category
    
    EXAMPLES::
    
        sage: # Equalizer diagram in Groups
        sage: G, H = CyclicGroup(6), CyclicGroup(4)
        sage: f = G.hom(H, ...)
        sage: g = G.hom(H, ...)  
        sage: diag = parallel_morphisms_diagram(f, g, Groups())
        sage: 
        sage: # Compute equalizer
        sage: E, e = diag.equalizer()
    """
    if f.domain() != g.domain() or f.codomain() != g.codomain():
        raise ValueError("Morphisms must be parallel")
    
    pp = parallel_pair_category()
    
    return DigraphDiagram(
        pp,
        target_category,
        object_map={0: f.domain(), 1: f.codomain()},
        morphism_map={
            pp.morphism(0, 1, ['f']): f,
            pp.morphism(0, 1, ['g']): g
        }
    )

def span_diagram(f, g, target_category):
    """
    Create a span diagram X ← Z → Y for pushouts.
    
    INPUT:
    - f: morphism Z → X
    - g: morphism Z → Y
    - target_category: where the diagram lives
    
    EXAMPLES::
    
        sage: # Pushout diagram in Sets
        sage: f: Z → X
        sage: g: Z → Y
        sage: diag = span_diagram(f, g, Sets())
        sage: P, injections = diag.pushout()
    """
    if f.domain() != g.domain():
        raise ValueError("Morphisms must have common domain")
    
    # Create span digraph: 1 ← 0 → 2
    G = DiGraph([(0, 1, 'left'), (0, 2, 'right')])
    span_cat = DigraphCategory(G)
    
    return DigraphDiagram(
        span_cat,
        target_category,
        object_map={0: f.domain(), 1: f.codomain(), 2: g.codomain()},
        morphism_map={
            span_cat.morphism(0, 1, ['left']): f,
            span_cat.morphism(0, 2, ['right']): g
        }
    )
```

## Benefits Over Poset Categories

### **1. Multiple Morphisms**
- **Parallel Pairs**: Can have f, g: X ⟹ Y for equalizers
- **Multiple Paths**: Different ways to go from X to Y
- **Rich Structure**: Not limited to thin categories

### **2. More Diagram Shapes**
- **Parallel morphisms**: Essential for (co)equalizers
- **Walking structures**: Walking arrow, walking isomorphism
- **Complex diagrams**: Arbitrary directed graphs

### **3. Free Construction**
- **Universal Property**: Extends uniquely to any category
- **No Constraints**: Paths are freely generated (until we quotient)
- **Flexible**: Can add relations later via quotients

### **4. Categorical Completeness**
With both poset and digraph categories, we can construct:
- Products/coproducts (discrete poset)
- Equalizers/coequalizers (parallel pair digraph)  
- Pullbacks/pushouts (span/cospan poset or digraph)
- General limits/colimits (any digraph diagram)

---

## Comparison: Posets vs Digraphs

| Feature | Poset Categories | Digraph Categories |
|---------|-----------------|-------------------|
| **Morphisms** | At most one | Arbitrarily many |
| **Structure** | Order relation | Free paths |
| **Best for** | Products, pullbacks | Equalizers, general diagrams |
| **Efficiency** | Very efficient | More complex |
| **Relations** | Built-in (transitivity) | Must add explicitly |

Together, these give us complete flexibility for constructing diagram categories!
