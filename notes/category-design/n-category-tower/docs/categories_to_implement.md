# The 2-Category C = Cat
A category in which all categories of interest are objects, and functors between form internal homs in Cat.

- join(C, D): the **join** of C and D, denoted C ⋆ D, which is the category formed by taking the disjoint union of C and D and adding a morphism from every object in C to every object in D.
- meet(C, D): the **meet** of C and D, denoted C ⋉ D, which is the category formed by taking the disjoint union of C and D and adding a morphism from every object in D to every object in C.
- op(C): the **opposite** category C^op.

## Classical Categories: Objects in Cat

- terminal_object(): * in C.
- initial_object(): ∅ in C.
- zero_object(): 0 in C, or NotWellDefinedError if C is not pointed.

- generators(): a set of objects {X_1, ..., X_n} are **generators** for C iff every object Y in C is a colimit of objects from {X_1, ..., X_n}.

- an_object(): returns an arbitrary object in C.
- some_objects(): returns a list of some objects in C.
- a_morphism(): returns an arbitrary morphism in C.
    - an_endomorphism(): returns an arbitrary endomorphism in C.

    - a_two_endomorphism(): returns an arbitrary 2-endomorphism in C.
    - a_two_automorphism(): returns an arbitrary 2-automorphism in C.

# The Category C = Set

- difference(data): 
    - Note: this is a purely relative notion!
    - If data is a pair (X, Y) where X "naturally" sits inside Y in a known way, explicitly construct a morphism f: X -> Y and go to the next case.

# The Category C = RMod

- base_change_functor(f): given a ring homomorphism f: R -> S, returns the functor F: RMod -> SMod defined by F(M) = M ⊗_R S.


## Objects in RMod
R-modules M.

- zero(): 0_M
- additive_identity(): zero()
- support(): the set of prime ideals P in R such that M_P ≠ 0 as a list of slice objects in Rings_{/R}.
- annihilator(): Ann_R(M) as an ideal in Rings_{/R}.
- base_change(f): RMod.base_change_functor(f)(self)


### Elements in RMod
m in M.

- add(y): x + y
- scalar_multiply(r): r ⋅ x
- additive_inverse()
- to_submodule(): the submodule generated by x as a slice object in RMod_{/M}
- is_zero(): x == 0_M
- is_additive_unit(): is_zero()
- annihilator(): Ann_R(x) as an ideal in Rings_{/R}.
- is_torsion(): True if there exists r ≠ 0 in R such that r ⋅ x = 0_M, else False.
- torsion_order(): the minimal such r in R such that r ⋅ x = 0_M, else infty
