# Interface: HyperbolicLattices

Hyperbolic lattices inherit all methods from `IndefiniteLattices` and add:

## Hyperbolic Space Model

```python
def hyperbolic_space_model(self):
    r"""
    Return the hyperboloid model of hyperbolic space.
    
    For signature (1, n-1, 0), this is the connected component
    {v ∈ L ⊗ R : ⟨v,v⟩ = 1, v in future cone}.
    """

def klein_model(self):
    r"""
    Return the Klein (projective) model of hyperbolic space.
    
    This is the image of the hyperboloid model under projection
    from the origin to a spacelike hyperplane.
    """

def poincare_ball_model(self):
    r"""
    Return the Poincaré ball model of hyperbolic space.
    
    This is obtained via stereographic projection.
    """
```

## Vinberg's Algorithm

```python
def vinberg_algorithm_applicable(self):
    r"""
    Test if Vinberg's algorithm can be applied to this lattice.
    
    Vinberg's algorithm applies to hyperbolic lattices of signature (1, n-1, 0)
    under certain arithmetic conditions.
    """
    # Check arithmetic conditions for Vinberg's algorithm
    return self._check_vinberg_conditions()

def vinberg_algorithm(self, root_norm_bound=2, max_distance=None):
    r"""
    Run Vinberg's algorithm to find a fundamental domain.
    
    Attempts to find a Coxeter polyhedron in hyperbolic space
    bounded by reflection hyperplanes.
    
    INPUT:
    - root_norm_bound: Maximum norm for root vectors
    - max_distance: Maximum distance from origin in hyperbolic space
    
    OUTPUT:
    - Coxeter diagram if successful
    - List of simple roots
    - Fundamental polyhedron
    """

def simple_roots_upto_norm(self, bound):
    r"""
    Find potential simple roots up to given norm bound.
    
    These are primitive vectors v with -bound ≤ ⟨v,v⟩ < 0
    that could serve as simple roots in a reflection group.
    """

def controlling_roots(self, simple_roots):
    r"""
    Find controlling roots for the given simple root system.
    
    These are roots that help determine if the fundamental domain
    has finite volume.
    """
```

## Reflection Groups

```python
def arithmetic_reflection_group(self):
    r"""
    Return the arithmetic reflection group if it exists.
    
    This is the group generated by reflections in vectors of
    negative norm in the lattice.
    """

def is_reflective(self):
    r"""
    Test if the lattice is reflective.
    
    A hyperbolic lattice is reflective if its arithmetic reflection
    group has finite covolume in the isometry group.
    """

def reflection_subgroup(self, roots):
    r"""
    Return the reflection subgroup generated by given roots.
    
    INPUT:
    - roots: List of root vectors (with negative norm)
    
    OUTPUT:
    Matrix group generated by reflections in these roots
    """
```

## Coxeter Polytopes

```python
def coxeter_polytope(self, simple_roots):
    r"""
    Return the Coxeter polytope defined by given simple roots.
    
    This is the fundamental domain for the reflection group
    generated by reflections in the simple roots.
    """

def is_finite_volume(self, simple_roots):
    r"""
    Test if the Coxeter polytope has finite volume.
    
    Uses Vinberg's criterion based on the Gram matrix of simple roots.
    """

def is_compact(self, simple_roots):
    r"""
    Test if the Coxeter polytope is compact.
    
    Equivalent to checking if there are no affine subdiagrams
    in the Coxeter diagram.
    """

def volume(self, simple_roots):
    r"""
    Compute the hyperbolic volume of the Coxeter polytope.
    
    Uses Lobachevsky's formula or generalizations.
    """
```

## Special Properties

```python
def is_lanner(self):
    r"""
    Test if this gives a compact hyperbolic Coxeter polytope.
    
    Lannér diagrams are the compact hyperbolic Coxeter diagrams.
    """

def cusp_count(self, simple_roots):
    r"""
    Count the number of cusps (ideal vertices) of the Coxeter polytope.
    
    Each maximal parabolic subdiagram corresponds to a cusp.
    """

def parabolic_subdiagrams(self, simple_roots):
    r"""
    Find all maximal parabolic (affine type) subdiagrams.
    
    These correspond to cusps of the fundamental domain.
    """
```
