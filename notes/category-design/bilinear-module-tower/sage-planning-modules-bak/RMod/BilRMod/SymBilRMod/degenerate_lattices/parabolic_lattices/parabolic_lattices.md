# Interface: ParabolicLattices

Parabolic lattices inherit all methods from `DegenerateLattices` and add:

**INHERITANCE CHAIN**: 
- FreeModules → FreeBilinearModules → SymmetricBilinearModules → DegenerateLattices → ParabolicLattices
- Signature is always (0, n-1, 1) following our negative definite convention
- The quotient L/rad(L) is a negative definite lattice

## Specialized Properties

```python
def is_parabolic(self):
    r"""Always returns True for parabolic lattices."""
    return True

def radical_rank(self):
    r"""Always returns 1 for parabolic lattices."""
    return 1

def null_vector(self):
    r"""
    Return a generator of the 1-dimensional radical.
    
    For parabolic lattices, rad(L) = Zδ for some primitive δ.
    """

def level(self):
    r"""
    Return the level of the parabolic lattice.
    
    This is the divisibility of the null vector in L*/L.
    """
```

## Affine Structure

```python
def affine_root_system(self):
    r"""
    Return the affine root system if this is an affine root lattice.
    
    Parabolic lattices often arise as root lattices of affine Lie algebras.
    """

def real_roots(self):
    r"""
    Return the real roots (those not proportional to δ).
    
    These are the roots with nonzero level.
    """

def imaginary_roots(self):
    r"""
    Return the imaginary roots (multiples of δ).
    
    These form the radical of the lattice.
    """

def fundamental_alcove(self):
    r"""
    Return the fundamental alcove if this is an affine root lattice.
    
    This is the fundamental domain for the affine Weyl group action.
    """
```

## Finite Part

```python
def finite_part(self):
    r"""
    Return the finite part L/rad(L).
    
    This is a negative definite lattice.
    """

def finite_root_system(self):
    r"""
    Return the finite root system on L/rad(L).
    
    For affine root lattices, this recovers the underlying finite type.
    """

def canonical_central_charge(self):
    r"""
    Return the canonical central charge.
    
    For affine root lattices, this is related to the dual Coxeter number.
    """
```

## Height Function

```python
def height(self, v):
    r"""
    Return the height of a vector.
    
    This is the coefficient of δ when v is expressed in terms
    of a basis including δ.
    """

def height_zero_sublattice(self):
    r"""
    Return the sublattice of height-zero vectors.
    
    This is rad(L)^⊥ ∩ L.
    """

def grading_by_height(self):
    r"""
    Return the grading of L by height.
    
    L = ⊕_{n∈Z} L_n where L_n = {v ∈ L : height(v) = n}.
    """
```

## Affine Weyl Group

```python
def affine_weyl_group(self):
    r"""
    Return the affine Weyl group if applicable.
    
    This is the group generated by reflections in real roots.
    """

def translation_subgroup(self):
    r"""
    Return the translation subgroup of the affine Weyl group.
    
    These are translations by vectors in the coroot lattice.
    """

def fundamental_weights(self):
    r"""
    Return the fundamental weights of the affine root system.
    
    These include the finite fundamental weights plus Λ_0.
    """
```

# Mathematical assertion: Affine root systems have exactly one zero eigenvalue (parabolic property)
# sage: A3_affine = RootSystem(['A', 3, 1])
# sage: cartan = A3_affine.cartan_matrix()
# sage: eigenvals = cartan.characteristic_polynomial().roots(multiplicities=False)
# sage: zero_eigenvals = [ev for ev in eigenvals if ev == 0]
# sage: len(zero_eigenvals)
# 1  # Exactly one zero eigenvalue (Kac, Ch 4)

# Mathematical assertion: Parabolic lattices have signature (0,n-1,1) following negative definite convention
# sage: A2_affine = RootSystem(['A', 2, 1])
# sage: gram = -A2_affine.cartan_matrix()  # Negative of Cartan for our convention
# sage: pos, neg, zero = gram.signature()
# sage: (pos, neg, zero)
# (0, 2, 1)  # Signature (0,n-1,1) for affine A2

# Mathematical assertion: The null root generates the radical (1-dimensional)
# sage: B3_affine = RootSystem(['B', 3, 1])
# sage: delta = B3_affine.null_root()
# sage: delta.inner_product(delta)
# 0  # Null root is isotropic (zero inner product with itself)

# Mathematical assertion: Real roots have nonzero height, imaginary roots are multiples of delta
# sage: A1_affine = RootSystem(['A', 1, 1])
# sage: Q = A1_affine.root_lattice()
# sage: alpha = Q.simple_roots()
# sage: alpha[0].inner_product(A1_affine.null_root()) != 0
# True  # Real roots are not orthogonal to null root

# Mathematical assertion: Finite part is recovered by quotient by radical
# sage: D4_affine = RootSystem(['D', 4, 1])
# sage: finite_part = RootSystem(['D', 4])
# sage: D4_affine.cartan_matrix().rank() - 1 == finite_part.cartan_matrix().rank()
# True  # Affine has one more dimension than finite part

# Mathematical assertion: Affine Weyl group contains translations by coroot lattice
# sage: A2_affine = RootSystem(['A', 2, 1])
# sage: W_affine = A2_affine.root_lattice().weyl_group()
# sage: W_finite = RootSystem(['A', 2]).root_lattice().weyl_group()
# sage: W_affine.is_finite()
# False  # Affine Weyl group is infinite (contains translations)

# Mathematical assertion: Level function measures coefficient of null root
# sage: C3_affine = RootSystem(['C', 3, 1])
# sage: Q = C3_affine.root_lattice()
# sage: delta = C3_affine.null_root()

# sage: (simple_roots[0] + delta).coefficient(0)  # Coefficient of alpha_0 (related to delta)
# 1  # Level measures the "delta-coefficient"

# Mathematical assertion: Fundamental weights include both finite weights and Lambda_0
# sage: A3_affine = RootSystem(['A', 3, 1])
# sage: P = A3_affine.weight_lattice()
# sage: Lambda = P.fundamental_weights()
# sage: len(Lambda)
# 4  # One more fundamental weight than finite type (includes Lambda_0)
