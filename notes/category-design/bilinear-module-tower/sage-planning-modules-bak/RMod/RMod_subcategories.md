# Module-Specific Axioms: Free, FinitelyGenerated, WithBasis

These axioms are specific to module categories and similar algebraic structures. While they could potentially be generalized, they are most naturally understood in the context of modules.

## Axiom: FinitelyGenerated

```python
class FinitelyGenerated(CategoryWithAxiom):
    """
    The axiom for finitely generated objects in module categories.
    
    An R-module M is finitely generated if there exists a finite subset
    S ⊂ M such that M = ⟨S⟩_R (the R-span of S).
    
    This axiom can apply to:
    - Modules over rings
    - Algebras over fields
    - Groups (finitely generated groups)
    - Ideals in rings
    
    EXAMPLES::
    
        sage: from sage.categories.modules import Modules
        sage: M = Modules(ZZ).FinitelyGenerated()
        sage: M
        Category of finitely generated modules over Integer Ring
        
        sage: # Z/nZ is finitely generated but not free
        sage: Zmod6 = ZZ.quotient(6*ZZ)
        sage: Zmod6 in Modules(ZZ).FinitelyGenerated()
        True
        sage: Zmod6 in Modules(ZZ).Free()
        False
        
        sage: # Polynomial rings are f.g. as modules over themselves
        sage: R.<x> = PolynomialRing(QQ)
        sage: R in Modules(R).FinitelyGenerated()
        True  # Generated by 1
    """
    
    class ParentMethods:
        def generators(self):
            """
            Return a finite generating set.
            
            OUTPUT:
            A finite family of elements that generate this module.
            
            EXAMPLES::
            
                sage: M = ZZ^3
                sage: M.generators()
                ((1, 0, 0), (0, 1, 0), (0, 0, 1))
                
                sage: # For quotient modules
                sage: N = M.quotient(M.span([(1, 1, 0)]))
                sage: len(N.generators()) < infinity
                True
            """
            raise NotImplementedError
        
        def number_of_generators(self):
            """
            Return the minimum number of generators needed.
            
            This is well-defined for finitely generated modules.
            
            EXAMPLES::
            
                sage: M = ZZ^3
                sage: M.number_of_generators()
                3
                
                sage: # For Z/6Z as Z-module
                sage: Zmod6 = ZZ.quotient(6*ZZ)
                sage: Zmod6.number_of_generators()
                1  # Generated by 1 mod 6
            """
            raise NotImplementedError
        
        def is_finitely_presented(self):
            """
            Test if this module is finitely presented.
            
            A module is finitely presented if it has a presentation
            with finitely many generators and finitely many relations.
            
            EXAMPLES::
            
                sage: ZZ^3.is_finitely_presented()
                True  # Free modules are finitely presented
                
                sage: # Over Noetherian rings, f.g. implies f.p.
                sage: R = ZZ
                sage: R.is_noetherian()
                True
            """
            raise NotImplementedError


## Axiom: Free

```python  
class Free(CategoryWithAxiom):
    """
    The axiom for free objects in concrete categories.
    
    A free R-module satisfies the universal property: for any R-module M
    and any map from a set S to M, there exists a unique R-module
    homomorphism from Free(S) to M extending the map.
    
    Key properties:
    - Free modules are projective
    - Free modules are flat
    - Submodules of free modules over a PID are free
    
    This axiom generalizes to:
    - Free groups
    - Free algebras  
    - Free monoids
    - Polynomial rings (free commutative algebras)
    
    EXAMPLES::
    
        sage: from sage.categories.modules import Modules
        sage: F = Modules(ZZ).Free()
        sage: F
        Category of free modules over Integer Ring
        
        sage: ZZ^3 in F
        True
        
        sage: # Free but not finitely generated
        sage: R.<x> = PolynomialRing(ZZ)
        sage: R in Modules(ZZ).Free()
        True  # Free on {1, x, x^2, ...}
        sage: R in Modules(ZZ).FinitelyGenerated()
        False  # Infinite basis as Z-module
    """
    
    class ParentMethods:
        def basis(self):
            """
            Return a basis of this free module.
            
            This may be infinite. A basis is a linearly independent
            generating set.
            
            EXAMPLES::
            
                sage: M = ZZ^3
                sage: list(M.basis())
                [(1, 0, 0), (0, 1, 0), (0, 0, 1)]
                
                sage: # Infinite basis example
                sage: R.<x> = PolynomialRing(QQ)
                sage: # R.basis() would be {1, x, x^2, x^3, ...}
            """
            raise NotImplementedError
        
        def rank(self):
            """
            Return the rank (dimension) of this free module.
            
            May return infinity for infinite rank free modules.
            
            EXAMPLES::
            
                sage: ZZ^5.rank()
                5
                
                sage: R.<x> = PolynomialRing(ZZ)
                sage: R.rank()  # As Z-module
                +Infinity
            """
            raise NotImplementedError
        
        def is_projective(self):
            """
            Free modules are always projective.
            
            A module P is projective if every surjection onto P splits.
            
            EXAMPLES::
            
                sage: M = ZZ^3
                sage: M.is_projective()
                True
                
                sage: # Direct summands of free modules are projective
                sage: # but may not be free
            """
            return True
        
        def universal_property(self, target, map_on_basis):
            """
            Implement the universal property of free modules.
            
            Given a map from the basis to a target module, extend
            uniquely to a module homomorphism.
            
            INPUT:
            - target -- an R-module
            - map_on_basis -- dictionary or function from basis to target
            
            OUTPUT:
            The unique module homomorphism extending map_on_basis
            
            EXAMPLES::
            
                sage: F = ZZ^3
                sage: G = ZZ^2
                sage: # Define map on basis
                sage: basis_map = {0: G([1,0]), 1: G([1,1]), 2: G([0,1])}
                sage: phi = F.universal_property(G, basis_map)
                sage: phi(F.basis()[0]) == G([1,0])
                True
            """
            raise NotImplementedError


## Axiom: WithBasis

```python
class WithBasis(CategoryWithAxiom):
    """
    The axiom for free modules with a distinguished basis.
    
    This is a stronger structure than just being free - it includes
    a specific chosen basis that enables coordinate representations.
    
    Key features:
    - Every element has unique coordinates
    - Arithmetic uses coordinate-wise operations
    - Natural conversion to/from vectors
    - Basis is indexed by some index set
    
    This is specific to modules and cannot easily generalize to
    other categories (groups don't have scalar multiplication).
    
    EXAMPLES::
    
        sage: from sage.categories.modules import Modules  
        sage: C = Modules(QQ).WithBasis()
        sage: C
        Category of modules with basis over Rational Field
        
        sage: # Standard example
        sage: V = CombinatorialFreeModule(QQ, ['a', 'b', 'c'])
        sage: V in C
        True
        
        sage: # Can have infinite basis
        sage: F = CombinatorialFreeModule(QQ, ZZ)  # Indexed by integers
        sage: F in Modules(QQ).WithBasis()
        True
        sage: F in Modules(QQ).FinitelyGenerated()
        False
    """
    
    def super_categories(self):
        """
        Modules with basis are free modules.
        
        Having a basis implies being free, but not conversely
        (free modules may not have a distinguished basis).
        
        EXAMPLES::
        
            sage: Modules(ZZ).WithBasis().super_categories()
            [Category of free modules over Integer Ring]
        """
        from sage.categories.modules import Modules
        return [Modules(self.base_ring()).Free()]
    
    class ParentMethods:
        def basis(self):
            """
            Return the distinguished basis family.
            
            OUTPUT:
            A family indexed by the basis keys, whose values are
            the basis elements.
            
            EXAMPLES::
            
                sage: M = CombinatorialFreeModule(QQ, ['x', 'y', 'z'])
                sage: B = M.basis()
                sage: B['x']
                B['x']
                sage: list(B)
                [B['x'], B['y'], B['z']]
            """
            raise NotImplementedError
        
        def basis_keys(self):
            """
            Return the index set for the basis.
            
            EXAMPLES::
            
                sage: M = CombinatorialFreeModule(QQ, ['a', 'b', 'c'])
                sage: M.basis_keys()
                {'a', 'b', 'c'}
                
                sage: # Can be infinite
                sage: F = CombinatorialFreeModule(QQ, ZZ)
                sage: F.basis_keys()
                Integer Ring
            """
            raise NotImplementedError
        
        def monomial(self, index):
            """
            Return the basis element indexed by 'index'.
            
            This is the preferred way to access basis elements.
            
            EXAMPLES::
            
                sage: M = CombinatorialFreeModule(QQ, ['x', 'y', 'z'])
                sage: M.monomial('y')
                B['y']
                
                sage: # Often denoted M.B[index] for brevity
                sage: M.B['y']
                B['y']
            """
            raise NotImplementedError
        
        def term(self, index, coefficient=None):
            """
            Return coefficient * basis_element.
            
            EXAMPLES::
            
                sage: M = CombinatorialFreeModule(QQ, ['a', 'b'])
                sage: M.term('a', 3)
                3*B['a']
                
                sage: M.term('b')  # Default coefficient is 1
                B['b']
            """
            raise NotImplementedError
        
        def from_vector(self, vector, order=None):
            """
            Create element from coordinate vector.
            
            INPUT:
            - vector -- coordinate vector
            - order -- (optional) ordering of basis elements
            
            EXAMPLES::
            
                sage: M = CombinatorialFreeModule(QQ, ['x', 'y', 'z'])
                sage: v = vector([2, -1, 3])
                sage: M.from_vector(v)
                2*B['x'] - B['y'] + 3*B['z']
            """
            raise NotImplementedError
    
    class ElementMethods:
        def to_vector(self, order=None):
            """
            Return coordinate vector with respect to the basis.
            
            EXAMPLES::
            
                sage: M = CombinatorialFreeModule(QQ, ['a', 'b', 'c'])
                sage: v = 2*M.B['a'] - 3*M.B['c']
                sage: v.to_vector()
                (2, 0, -3)
            """
            raise NotImplementedError
        
        def coefficient(self, index):
            """
            Return the coefficient of a basis element.
            
            EXAMPLES::
            
                sage: M = CombinatorialFreeModule(QQ, ['x', 'y'])
                sage: v = 3*M.B['x'] - 2*M.B['y']
                sage: v.coefficient('x')
                3
                sage: v.coefficient('y')
                -2
                sage: v.coefficient('z')  # Not a basis element
                0
            """
            raise NotImplementedError
        
        def monomial_coefficients(self, copy=True):
            """
            Return dictionary of non-zero coefficients.
            
            EXAMPLES::
            
                sage: M = CombinatorialFreeModule(QQ, ['a', 'b', 'c'])
                sage: v = 2*M.B['a'] - M.B['c']
                sage: v.monomial_coefficients()
                {'a': 2, 'c': -1}
            """
            raise NotImplementedError
```

## Relationships Between Axioms

### Implications
- `WithBasis` ⊆ `Free` (having a distinguished basis implies being free)
- `WithBasis` ∩ `FinitelyGenerated` = modules with finite basis
- `Free` ∩ `FinitelyGenerated` = finite rank free modules

### Non-implications  
- `FinitelyGenerated` ⊄ `Free` (e.g., Z/nZ is f.g. but not free)
- `Free` ⊄ `FinitelyGenerated` (e.g., polynomial rings as modules)
- `Free` ⊄ `WithBasis` (abstract free modules may not have chosen basis)

### Examples

```sage
# Finitely generated, not free
sage: Zmod6 = Integers(6)
sage: Zmod6 in Modules(ZZ).FinitelyGenerated()
True
sage: Zmod6 in Modules(ZZ).Free()
False

# Free, not finitely generated  
sage: R.<x> = PolynomialRing(ZZ)
sage: R in Modules(ZZ).Free()
True  # Basis {1, x, x^2, ...}
sage: R in Modules(ZZ).FinitelyGenerated()
False

# With finite basis (all three axioms)
sage: M = CombinatorialFreeModule(QQ, ['a', 'b', 'c'])
sage: M in Modules(QQ).WithBasis()
True
sage: M in Modules(QQ).Free()
True  
sage: M in Modules(QQ).FinitelyGenerated()
True

# With infinite basis
sage: F = CombinatorialFreeModule(QQ, ZZ)
sage: F in Modules(QQ).WithBasis()
True
sage: F in Modules(QQ).Free()
True
sage: F in Modules(QQ).FinitelyGenerated()
False
```

## Design Rationale

These axioms are naturally module-specific because:

1. **FinitelyGenerated** - While applicable to groups and algebras, the definition and properties differ significantly

2. **Free** - The universal property is formulated in terms of module homomorphisms and scalar multiplication

3. **WithBasis** - Fundamentally requires scalar multiplication and linear combinations, specific to modules

Unlike abelian or monoidal structures which are purely categorical, these axioms depend on the concrete nature of modules as sets with operations.
