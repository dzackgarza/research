# Subcategories: RModules(R) Axiom-Based Specializations

Axiom-based subcategories for R-modules focusing on structural properties: Free, FinitelyGenerated, WithBasis, and their combinations.

## Axiom Organization

```python
from sage.categories.category_with_axiom import CategoryWithAxiom
from sage.categories.category_types import AbelianCategory

class RModulesWithAxiom(CategoryWithAxiom):
    """
    Base class for R-module axioms.
    
    Provides framework for axiom-based specialization of R-modules
    with structural properties determining subcategory membership.
    
    Key axioms for R-modules:
    - Free: Universal property of free modules
    - FinitelyGenerated: Has finite generating set
    - WithBasis: Free with distinguished basis (additional structure)
    - Torsion: Every element has finite order
    - TorsionFree: No non-zero torsion elements
    - Projective: Direct summand of free module
    - Injective: Extension property for morphisms
    - Flat: Tensor product preserves exact sequences
    """
    pass
```

## Free R-Modules

```python
class Free(RModulesWithAxiom):
    """
    Free R-modules satisfying the universal property.
    
    An R-module F is free if there exists a set S (basis) such that:
    - Every element of F can be uniquely written as a finite R-linear combination of elements in S
    - F satisfies the universal property: for any R-module M and function f: S → M,
      there exists a unique R-module homomorphism φ: F → M extending f
    
    Properties:
    - Has a basis (possibly infinite)
    - Isomorphic to R^(S) for some set S
    - Rank is well-defined (cardinality of basis)
    - Every submodule of a free module over a PID is free
    - Projective (lifts along surjections)
    - Flat (tensor product preserves exactness)
    
    EXAMPLES::
    
        sage: C = RModules(ZZ).Free()
        sage: C
        Category of free modules over Integer Ring
        
        sage: M = RModule(ZZ, rank=3)  # Free module of rank 3
        sage: M in C
        True
        sage: M.is_free()
        True
        sage: M.rank()
        3
        
        sage: # Polynomial ring as free module
        sage: R.<x> = PolynomialRing(QQ)
        sage: R in RModules(QQ).Free()
        True  # Countably infinite basis {1, x, x^2, ...}
    """
    
    class ParentMethods:
        def rank(self):
            """
            Return the rank (cardinality of any basis).
            
            The rank is an invariant - all bases have the same cardinality.
            
            OUTPUT:
            Integer or Infinity
            
            EXAMPLES::
            
                sage: M = RModule(ZZ, rank=5)
                sage: M.rank()
                5
                
                sage: R.<x> = PolynomialRing(QQ)
                sage: R.rank()
                +Infinity
            """
            pass
        
        def is_free(self):
            """Always True for objects in Free category."""
            return True
        
        def basis_cardinality(self):
            """Alias for rank()."""
            return self.rank()
        
        def has_finite_rank(self):
            """Test if rank is finite."""
            return self.rank() < Infinity
        
        def is_trivial(self):
            """Test if this is the zero module (rank 0)."""
            return self.rank() == 0
        
        def direct_sum_decomposition(self):
            """
            Return decomposition as direct sum of rank-1 free modules.
            
            Every free module decomposes as ⊕ R (indexed by basis).
            
            OUTPUT:
            List of rank-1 free submodules
            """
            if not self.has_finite_rank():
                raise ValueError("Decomposition only implemented for finite rank")
            
            # Return list of cyclic submodules generated by basis elements
            return [self.submodule([b]) for b in self.basis()]
        
        def exterior_power(self, k):
            """
            Return the k-th exterior power ∧^k(M).
            
            For free module of rank n, ∧^k has rank (n choose k).
            
            INPUT:
            - k -- non-negative integer
            
            OUTPUT:
            Free module representing k-th exterior power
            """
            n = self.rank()
            if k > n:
                # Exterior power is zero for k > rank
                return self.base_ring().zero_module()
            
            from sage.arith.misc import binomial
            new_rank = binomial(n, k)
            return RModule(self.base_ring(), rank=new_rank)
    
    class ElementMethods:
        def is_basis_element(self):
            """Test if this element is in some basis."""
            # Element is basis element if it generates rank-1 free submodule
            submod = self.parent().submodule([self])
            return submod.rank() == 1
        
        def extends_to_basis(self):
            """
            Test if this element can be extended to a basis.
            
            True if and only if element is not in any proper submodule.
            """
            if self.is_zero():
                return False
            
            # For finite rank: element extends to basis iff it's not zero
            # and the quotient by its span is free of rank n-1
            parent = self.parent()
            if parent.has_finite_rank():
                quotient = parent.quotient(parent.submodule([self]))
                return quotient.is_free() and quotient.rank() == parent.rank() - 1
            
            # General case requires more sophisticated algorithm
            raise NotImplementedError("Basis extension for infinite rank")
    
    class HomsetMethods:
        def basis_matrix(self):
            """
            Matrix representation using bases of domain and codomain.
            
            Only defined when both modules are free with finite rank.
            
            OUTPUT:
            Matrix over base ring
            """
            if not (self.domain().is_free() and self.codomain().is_free()):
                raise ValueError("Both modules must be free")
            
            if not (self.domain().has_finite_rank() and self.codomain().has_finite_rank()):
                raise ValueError("Both modules must have finite rank")
            
            # Matrix would be constructed from images of basis elements
            raise NotImplementedError("Basis matrix computation")

class WithBasis(RModulesWithAxiom):
    """
    Free R-modules with distinguished basis (additional structure).
    
    A module with basis is a free module together with a chosen ordered basis.
    This is additional structure, not just a property - the same free module
    can have different "with basis" structures.
    
    The basis provides:
    - Canonical isomorphism with R^n or R^(S)
    - Coordinate representation of elements
    - Matrix representation of morphisms
    - Computational advantages
    
    WithBasis ⊆ Free by definition (but Free ⊈ WithBasis).
    
    EXAMPLES::
    
        sage: C = RModules(QQ).WithBasis()
        sage: C
        Category of vector spaces with basis over Rational Field
        
        sage: M = CombinatorialFreeModule(QQ, ['a', 'b', 'c'])
        sage: M in C
        True
        sage: M.basis()
        Finite family {'a': B['a'], 'b': B['b'], 'c': B['c']}
        
        sage: # Polynomial ring with monomial basis
        sage: R.<x,y> = PolynomialRing(QQ)
        sage: R.basis()
        Family (x^i*y^j for i,j in NN × NN)
    """
    
    def extra_super_categories(self):
        """Having a basis implies being free."""
        from sage.categories.modules import Modules
        return [Modules(self.base_ring()).Free()]
    
    class ParentMethods:
        def basis(self):
            """
            Return the distinguished basis.
            
            The basis is typically indexed by some set (finite or infinite).
            
            OUTPUT:
            Family of basis elements indexed by basis keys
            
            EXAMPLES::
            
                sage: M = CombinatorialFreeModule(QQ, [1, 2, 3])
                sage: M.basis()
                Finite family {1: B[1], 2: B[2], 3: B[3]}
                
                sage: # Group algebra
                sage: G = SymmetricGroup(3)
                sage: QG = GroupAlgebra(G, QQ)
                sage: QG.basis()
                Finite family indexed by Symmetric group of order 3! as a permutation group
            """
            pass
        
        def basis_keys(self):
            """
            Return the index set for basis elements.
            
            OUTPUT:
            Set or enumerated set indexing the basis
            """
            return self.basis().keys()
        
        def dimension(self):
            """
            Return dimension (size of basis).
            
            Same as rank() but emphasizes basis structure.
            
            OUTPUT:
            Non-negative integer or Infinity
            """
            return self.basis().cardinality()
        
        def coordinate_module(self):
            """
            Return isomorphic coordinate module R^n or R^(S).
            
            This is the "standard" free module with same rank.
            
            OUTPUT:
            Free module with canonical basis
            """
            if self.dimension() < Infinity:
                return self.base_ring()^self.dimension()

        def coordinates(self, element):

            INPUT:
            - element -- element of this module
            
            OUTPUT:
            Vector in coordinate module
            """

            OUTPUT:
            Element of this module
            """
            return self._from_dict(dict(zip(self.basis_keys(), coords)))

            OUTPUT:
            Vector in coordinate module
            
            EXAMPLES::
            
                sage: M = CombinatorialFreeModule(QQ, ['a', 'b'])
                sage: x = 3*M.basis()['a'] + 2*M.basis()['b']
                sage: x.to_vector()

            INPUT:

            OUTPUT:

                sage: M = CombinatorialFreeModule(QQ, ['x', 'y', 'z'])

            """
            Return all non-zero coefficients.
            
            INPUT:
            - sort -- whether to sort by basis keys
            
            OUTPUT:
            List of coefficient values

                keys = sorted(self.support())
            else:
                keys = self.support()
            
            return [self.coefficient(k) for k in keys]

            """
            Return basis keys with non-zero coefficients.
            
            OUTPUT:
            List of basis keys
            """
            return [k for k in self.parent().basis_keys() 
                    if self.coefficient(k) != 0]
        
        def is_basis_element(self):
            """Test if element is a single basis element."""
            support = self.support()
            if len(support) != 1:
                return False
            
            # Check coefficient is 1
            return self.coefficient(support[0]) == 1
```

## Axiom Combinations and Relationships

```python
class FreeFinitelyGenerated(CategoryWithAxiom):
    """
    Free modules of finite rank.
    
    Intersection of Free and FinitelyGenerated.
    These are exactly the modules isomorphic to R^n.
    """
    
    def extra_super_categories(self):
        """Free and finitely generated."""
        R = self.base_ring()
        return [RModules(R).Free(), RModules(R).FinitelyGenerated()]


class FinitelyGeneratedWithBasis(CategoryWithAxiom):
    """
    Finitely generated modules with distinguished finite basis.
    
    This is equivalent to finite-dimensional vector spaces for fields.
    """
    
    def extra_super_categories(self):
        """With basis and finitely generated."""
        R = self.base_ring()
        return [RModules(R).WithBasis(), RModules(R).FinitelyGenerated()]

class Torsion(RModulesWithAxiom):
    """
    Torsion modules where every element has finite order.
    
    M is torsion if for every m ∈ M, there exists non-zero r ∈ R with rm = 0.
    """
    
    class ElementMethods:
        def order(self):

class TorsionFree(RModulesWithAxiom):
    """
    Modules with no non-zero torsion elements.
    
    M is torsion-free if rm = 0 with r ≠ 0 implies m = 0.
    Free modules are always torsion-free.
    """
    
    class ParentMethods:
        def is_torsion_free(self):
            """Always True for torsion-free modules."""
            return True
```

## Mathematical Properties

```python
# Mathematical assertion: Axiom implications
# WithBasis ⊆ Free (having basis implies freeness)
# Free ⊆ Projective (free modules lift morphisms)
# Free ⊆ Flat (free modules preserve exactness under tensor)
# Free ⊆ TorsionFree (no torsion in free modules)

# Mathematical assertion: Structure theorem over PIDs
# FinitelyGenerated over PID ≅ Free ⊕ Torsion
# Both summands are finitely generated

# Mathematical assertion: Rank invariance
# All bases of a free module have same cardinality

# Mathematical assertion: Finite generation properties
# Submodules of f.g. modules over Noetherian rings are f.g.
# Quotients of f.g. modules are always f.g.
# Finite direct sums of f.g. modules are f.g.

# Mathematical assertion: Basis properties
# WithBasis provides computational representation
# Coordinate isomorphism: M ≅ R^(basis_keys)

# Mathematical assertion: Universal property of free modules
# Hom(Free(S), M) ≅ M^S (functorially)
```

This comprehensive axiom framework enables proper categorization of R-modules based on their structural properties while maintaining the mathematical relationships between different axioms.
