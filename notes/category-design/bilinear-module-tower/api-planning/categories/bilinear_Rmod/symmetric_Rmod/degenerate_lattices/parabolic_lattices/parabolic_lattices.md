# Interface: ParabolicLattices

Parabolic lattices inherit all methods from `DegenerateLattices` and add:

**INHERITANCE CHAIN**: 
- FreeModules → FreeBilinearModules → SymmetricBilinearModules → DegenerateLattices → ParabolicLattices
- Signature is always (0, n-1, 1) following our negative definite convention
- The quotient L/rad(L) is a negative definite lattice

## Specialized Properties

```python
def is_parabolic(self):
    r"""Always returns True for parabolic lattices."""
    return True

def radical_rank(self):
    r"""Always returns 1 for parabolic lattices."""
    return 1

def null_vector(self):
    r"""
    Return a generator of the 1-dimensional radical.
    
    For parabolic lattices, rad(L) = Zδ for some primitive δ.
    """

def level(self):
    r"""
    Return the level of the parabolic lattice.
    
    This is the divisibility of the null vector in L*/L.
    """
```

## Affine Structure

```python
def affine_root_system(self):
    r"""
    Return the affine root system if this is an affine root lattice.
    
    Parabolic lattices often arise as root lattices of affine Lie algebras.
    """

def real_roots(self):
    r"""
    Return the real roots (those not proportional to δ).
    
    These are the roots with nonzero level.
    """

def imaginary_roots(self):
    r"""
    Return the imaginary roots (multiples of δ).
    
    These form the radical of the lattice.
    """

def fundamental_alcove(self):
    r"""
    Return the fundamental alcove if this is an affine root lattice.
    
    This is the fundamental domain for the affine Weyl group action.
    """
```

## Finite Part

```python
def finite_part(self):
    r"""
    Return the finite part L/rad(L).
    
    This is a negative definite lattice.
    """

def finite_root_system(self):
    r"""
    Return the finite root system on L/rad(L).
    
    For affine root lattices, this recovers the underlying finite type.
    """

def canonical_central_charge(self):
    r"""
    Return the canonical central charge.
    
    For affine root lattices, this is related to the dual Coxeter number.
    """
```

## Height Function

```python
def height(self, v):
    r"""
    Return the height of a vector.
    
    This is the coefficient of δ when v is expressed in terms
    of a basis including δ.
    """

def height_zero_sublattice(self):
    r"""
    Return the sublattice of height-zero vectors.
    
    This is rad(L)^⊥ ∩ L.
    """

def grading_by_height(self):
    r"""
    Return the grading of L by height.
    
    L = ⊕_{n∈Z} L_n where L_n = {v ∈ L : height(v) = n}.
    """
```

## Affine Weyl Group

```python
def affine_weyl_group(self):
    r"""
    Return the affine Weyl group if applicable.
    
    This is the group generated by reflections in real roots.
    """

def translation_subgroup(self):
    r"""
    Return the translation subgroup of the affine Weyl group.
    
    These are translations by vectors in the coroot lattice.
    """

def fundamental_weights(self):
    r"""
    Return the fundamental weights of the affine root system.
    
    These include the finite fundamental weights plus Λ_0.
    """
```

def string_function(self, highest_weight):
