Elements of lattices (nondegenerate integral lattices). Inherits from SymmetricBilinearModules elements.

```python
def div(self):
    r"""Return the divisibility of this element in the lattice."""

def dual(self):
    r"""
    Return the dual element v* ∈ L*.
    
    This is the image of v under the canonical embedding ι: L → L*.
    For w ∈ L, v*(w) = ⟨v, w⟩.
    
    OUTPUT:
    The dual element v* in the dual lattice L*.
    """

def discriminant_image(self):
    r"""
    Return the image of this element in the discriminant group A_L = L*/L.
    
    This is φ(v) = v*/d where φ: L → A_L is the canonical morphism.
    
    OUTPUT:
    The image of v in the discriminant group A_L.
    """
```

## Algebraic Lattice Elements (Symbolic Implementation)

This section describes the preferred implementation for lattice elements with symbolic basis manipulation.

### Design Philosophy

The algebraic lattice implementation provides:
- **Natural notation**: Support mathematical syntax like `2*e + 3*f` and `e*f`  
- **Symbolic basis access**: `L.e`, `L.f` attribute access
- **Bilinear form evaluation**: Direct `*` operator for inner products
- **Indefinite-first design**: Optimized for indefinite lattices
- **Minimal complexity**: Inherits from `FreeModule_generic` for control

### Core Element Implementation

```python
class AlgebraicLattice(FreeModule_generic):
    """
    A lattice with named basis and bilinear form, supporting natural algebraic notation.
    
    EXAMPLES::
    
        sage: # Hyperbolic plane U
        sage: U = AlgebraicLattice(['e', 'f'], 
        ....:                      bilinear_form={('e','e'): 0, ('f','f'): 0, 
        ....:                                     ('e','f'): 1, ('f','e'): 1})
        sage: e, f = U.e, U.f
        sage: v = 2*e + 3*f
        sage: v * v  # Bilinear form evaluation
        12
    """
    
    class Element(FreeModule_generic.Element):
        """
        Element of an algebraic lattice with symbolic basis.
        
        Supports natural arithmetic and bilinear form evaluation.
        """
        
        def __mul__(self, other):
            """
            Evaluate bilinear form if other is lattice element.
            Otherwise, do scalar multiplication.
            
            EXAMPLES::
            
                sage: U = AlgebraicLattice(['e', 'f'], 
                ....:                      bilinear_form={('e','f'): 1, ('f','e'): 1})
                sage: e, f = U.e, U.f
                sage: e * f  # Bilinear form
                1
                sage: 3 * e  # Scalar multiplication
                3*e
                sage: (e + f) * (e - f)  # Extended bilinearly
                -1
            """
            P = self.parent()
            
            # Check if other is in the same lattice (bilinear form evaluation)
            if hasattr(other, 'parent') and other.parent() is P:
                result = P.base_ring().zero()
                form = P._bilinear_form_dict
                
                # Sum over all pairs of monomials
                for key1, coeff1 in self._monomial_coefficients.items():
                    for key2, coeff2 in other._monomial_coefficients.items():
                        if (key1, key2) in form:
                            result += coeff1 * coeff2 * form[(key1, key2)]
                return result
            else:
                # Otherwise, treat as scalar multiplication
                return FreeModule_generic.Element.__mul__(self, other)
        
        def inner_product(self, other):
            """
            Alias for bilinear form evaluation.
            
            Some prefer this more explicit notation over v * w.
            """
            return self * other
        
        def _repr_(self):
            """
            Pretty print as sum of symbolic terms.
            
            EXAMPLES::
            
                sage: L = AlgebraicLattice(['a', 'b', 'c'])
                sage: 2*L.a - 3*L.b + L.c
                2*a - 3*b + c
            """
            if not self:
                return "0"
                
            terms = []
            for key, coeff in sorted(self._monomial_coefficients.items()):
                if coeff == 1:
                    terms.append(str(key))
                elif coeff == -1:
                    terms.append(f"-{key}")
                else:
                    # Handle sign explicitly
                    if coeff > 0 and terms:
                        terms.append(f"+ {coeff}*{key}")
                    else:
                        terms.append(f"{coeff}*{key}")
                        
            result = " ".join(terms)
            # Clean up spacing around operators
            result = result.replace(" + -", " - ")
            result = result.replace(" + +", " + ")
            return result
```

### Key Implementation Details

#### Minimal FreeModule_generic Base

The implementation inherits from `FreeModule_generic` instead of `CombinatorialFreeModule` for several reasons:

1. **Complete control**: ~100 lines vs thousands of lines of inheritance
2. **Performance**: No overhead from unused combinatorial features  
3. **Simplicity**: Easy to understand and maintain
4. **Flexibility**: Easy to customize for indefinite lattices

#### Attribute Access for Basis Elements

```python
def __getattr__(self, name):
    """
    Enable attribute access for basis elements.
    
    EXAMPLES::
    
        sage: L = AlgebraicLattice(['x', 'y', 'z'])
        sage: L.x
        x
        sage: L.y + L.z
        y + z
    """
    if name in self._basis_keys:
        return self.monomial(name)  # Use parent class method
    raise AttributeError(f"'{type(self).__name__}' has no attribute '{name}'")
```

#### Bilinear Form Storage

```python
def _setup_bilinear_form(self, bilinear_form):
    """Convert various bilinear form specifications to internal format."""
    if bilinear_form is None:
        # Default to zero form
        self._bilinear_form_dict = {}
    elif isinstance(bilinear_form, dict):
        self._bilinear_form_dict = bilinear_form
    elif hasattr(bilinear_form, 'nrows'):  # Matrix-like
        # Convert matrix to dictionary representation
        self._bilinear_form_dict = {}
        for i, key1 in enumerate(self._basis_keys):
            for j, key2 in enumerate(self._basis_keys):
                val = bilinear_form[i,j]
                if val != 0:
                    self._bilinear_form_dict[(key1, key2)] = val
    else:
        raise ValueError("bilinear_form must be dict or matrix")
```

```python

U = AlgebraicLattice(['e', 'f'],

# Natural arithmetic works
```

#### Integration with Algorithms

For indefinite lattices, the implementation automatically selects appropriate algorithms:

```python
def vectors_of_norm(self, n):
    """
    Find all vectors of given norm.
    
    Automatically selects appropriate algorithm based on signature.
    """
    if self.is_positive_definite():
        # Use fast IntegerLattice methods
        IL = IntegerLattice(self.gram_matrix())
        return [self(v) for v in IL.vectors_of_length(n)]
    else:
        # Use QuadraticForm for indefinite case
        QF = QuadraticForm(self.gram_matrix())
        vecs = QF.find_reps(n)
        return [self.from_vector(v) for v in vecs]
```

### Comparison: Minimal vs CombinatorialFreeModule

#### What We Get from FreeModule_generic

1. **Element Storage**: Efficient dictionary-based storage
2. **Basic Arithmetic**: `__add__`, `__sub__`, `__rmul__` all implemented  
3. **Coercion**: Automatic handling of scalar multiplication
4. **Category Integration**: Methods from `Modules` category
5. **Parent/Element Framework**: Proper Sage integration

#### What We Implement

1. **Basis Key Storage**: Simple tuple of names
2. **Attribute Access**: `__getattr__` for `M.e` syntax
3. **Bilinear Form**: Custom `__mul__` operator  
4. **Pretty Printing**: Optional `_repr_` customization

#### What CombinatorialFreeModule Adds (that we don't need)

1. **IndexedGenerators**: Complex basis indexing machinery
2. **UniqueRepresentation**: Caching and singleton behavior
3. **Graded Module Support**: Degree tracking infrastructure  
4. **Tensor Product Machinery**: Specialized tensor constructions
5. **Combinatorial Categories**: Integration with combinatorial objects

### Factory Functions

```python
def Lattice(arg1, arg2=None, **kwargs):
    """
    Unified constructor for lattices.
    
    EXAMPLES::
    
        sage: # From Gram matrix
        sage: L = Lattice(matrix([[2, -1], [-1, 2]]))
        
        sage: # From generators and relations  
        sage: U = Lattice(['e', 'f'], {('e','f'): 1, ('f','e'): 1})
        
        sage: # From Cartan type
        sage: A3 = Lattice("A3")
        
        sage: # Hyperbolic plane
        sage: H = Lattice("U")  # Recognizes standard lattices
    """
    if isinstance(arg1, str):
        # Handle named lattices and Cartan types
        return _construct_named_lattice(arg1, **kwargs)
    elif hasattr(arg1, 'nrows'):
        # Matrix -> use coordinate implementation
        return IntegralLattice(arg1, **kwargs)
    elif isinstance(arg1, (list, tuple)):
        # Basis keys -> use algebraic implementation
        return AlgebraicLattice(arg1, bilinear_form=arg2, **kwargs)
    else:
        raise ValueError("Cannot determine lattice construction type")
```

### Integration with Morphism Framework

The algebraic lattice seamlessly integrates with the existing morphism framework:

```python
# Define morphism by generator images
U1 = Lattice(['e', 'f'], bilinear_form={('e','f'): 1, ('f','e'): 1})
U2 = Lattice(['e_prime', 'f_prime'], 
             bilinear_form={('e_prime','f_prime'): 2, ('f_prime','e_prime'): 2})

phi = U1.hom([2*U2.e_prime, U2.f_prime])  # e ↦ 2e', f ↦ f'
```
