# Objects in Sp(BilR-Mod): Bilinear Module Spectra

Objects of the stable ∞-category Sp(BilR-Mod) are bilinear module spectra.

## Definition of Objects

A **bilinear module spectrum** E consists of:
1. A sequence of bilinear modules {E_n}_{n≥0}
2. Structure maps σ_n: ΣE_n → E_{n+1} (suspension maps)
3. Higher coherence data making this an object of the stable ∞-category
