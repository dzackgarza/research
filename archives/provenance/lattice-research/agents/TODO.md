# TODO scratchpad

This file is a non-authoritative inbox for tangential discoveries that need
investigation before they can become real Nimbalyst cards.

Do not use this file as an outstanding-work inventory, kanban lane, sprint plan, or
execution queue. Convert clear work into tracked files under `.agents/plans/features/`.

## Inbox

Use this shape for each entry:

```markdown
- Source: path/to/file.md or session context
  Observation: What was noticed.
  Why it matters: What may break, confuse, or need follow-up.
  Triage needed: research | task card | bug card | decision | plan | discard
```
