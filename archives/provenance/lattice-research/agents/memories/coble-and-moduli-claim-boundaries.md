Stored task facts:

- Task 1.1 rational sextic: degree-6 plane curve has arithmetic genus `10`; ten ordinary nodes each contribute delta `1`; ten nodes give geometric genus `0`. Birational parametrization check is generic-fiber degree `1`.
- Task 1.2 lattice pipeline: on the blowup of `P^2` at ten nodes, `Pic(S)` has generators `H, E_1,...,E_10`, signature `(1,10)`. The K3 double-cover pullback doubles intersections, giving expected Gram `diag(2,-2,...,-2) = <2> + <-2>^10`. Discriminant group/Nikulin invariants are outputs from the computed lattice, not inputs.
- Coble polarization normalization: `H` is the plane hyperplane class with `H^2 = 1`, and `f^*H` has square `2`; this is not the degree-2 Coble moduli polarization. In the blowup basis, `K_S = -3H + sum_i E_i`, so `D = aH - sum_i b_iE_i` is in `K_S^perp` iff `sum_i b_i = 3a`. The moduli polarization is `h_Co in K_S^perp subset Pic(S)`, non-degenerately `F_1 + F_2`, with `h_Co^2 = 2`; its K3 pullback `tilde h_Co = f^*h_Co` has square `4`.
- Task 1.3 embedding chain: `T_Co -> T_En -> T_dP -> Lambda_K3`, with `Lambda_K3 = U^3 + E_8(-1)^2`; `T_En = U + E_10(2)` has rank `12` and signature `(2,10)`, while `T_Co` is rank `11`, signature `(2,9)`. Primitive embeddings and complements route through Nikulin/Oscar, not hand-coded embedding matrices.
- Task 2.1 discriminant orbit input: start only after Task 1.2 computes and verifies the relevant rank-11 lattice and discriminant form. If `A_T = (Z/2Z)^11`, then `|A_T| = 2048` and stored theory expects `528` isotropic vectors including zero.
- Task 2.2 orbit lifting: divisibility must be derived from the actual Gram model. In the diagonal even model, pairings are even, so primitive isotropic vectors have divisibility `2`, not `1`.
- Task 3.1 arithmetic group: `Gamma_Co` must name the typed lift/transport of the degree-2 Coble polarization. Downstairs `h_Co^2 = 2`; K3-side `tilde h_Co^2 = 4`. Explicit generators are not yet computed in theory.
- Task 3.2 isotropic planes: maximal isotropic dimension is `2` for signature `(2,9)`. For primitive isotropic plane `J`, `J^perp/J` is negative definite of rank `7`. The predicted unique orbit and `A_1^7` quotient are unverified computationally; a prior bounded search found examples but did not perform the GAP orbit computation.
