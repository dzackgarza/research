## Classification Overview

### Finite Coxeter Groups

- **Series A_n**: W(A_n) ≅ S_{n+1}, the symmetric group on n+1 letters, order (n+1)!

- **Series B_n**: Hyperoctahedral groups (signed permutations), order 2^n · n!

- **Series D_n**: The index-2 subgroup of W(B_n) of signed permutations with an even number of sign changes, order 2^{n-1} · n!

- **Dihedral I_2(p)**: 2D reflection groups of order 2p; listed for p ≥ 5 in the irreducible classification, since I_2(3) = A_2, I_2(4) = B_2 and I_2(6) = G_2

- **Exceptional**: E_6, E_7, E_8, F_4, H_3, H_4, G_2

### Affine Coxeter Groups

- Infinite groups with finite quotient

- Extended Dynkin diagrams

- Examples: Ã1, B̃n, Ẽ6-Ẽ8, F̃4, G̃2

### Hyperbolic Coxeter Groups

- Infinite reflection groups in hyperbolic space

- Include hyperbolic triangle groups

## Mathematical Properties

### Generation

- Generated by reflections (involutions)

- Coxeter presentation: generators s_i with relations (s_i s_j)^{m_ij} = 1, where m_ii = 1 and m_ij = m_ji ∈ {2, 3, ...} ∪ {∞}; m_ij = ∞ means no relation

### Representation Theory

- Coxeter matrices encode generator relationships

- Coxeter diagrams provide visual representation

- Multiple partial orders: weak, Bruhat, absolute

### Key Theorems

1. **Finite Classification**: Complete list of finite irreducible types

2. **Crystallographic Groups**: Subset that are Weyl groups

3. **Word Problem**: Solvable for all Coxeter groups

## Applications

- Weyl groups of semisimple Lie algebras
