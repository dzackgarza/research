# The Two Most Algebraic K3 Surfaces

E.B.Vinberg Chair of Algebra, University of Moscow,SU-117234 Moscow,USSR

In this paper, we demonstrate an application of the theory of hyperbolic reflection groups to algebraic K3 surfaces.

Among algebraic K 3 surfaces (over the field of complex numbers) two surfaces, that we will denote by $X _ { 3 }$ and $X _ { 4 }$ ,are distinguished; their lattices of algebraic twodimensional cycles have the maximum possble dimension equal to 20 and the minimum possible moduli of discriminants equal to 3 and 4,respectively. In [8] it is shown that

1） the surface $X _ { m } ( m = 3 , 4 )$ is birationally isomorphic to $( Y _ { m } \times Y _ { m } ) / { \varGamma } _ { m } ,$ where $Y _ { m } = \mathbb { { C } } / ( \mathbb { Z } + \mathbb { Z } \omega _ { m } )$ for $\omega _ { m } = e ^ { \frac { 2 \pi i } { m } }$ is an elliptic curve, $T _ { m }$ is the cyclic group of order $m$ generated by the transformation $( z _ { 1 } , z _ { 2 } ) { \mapsto } ( { \omega } _ { m } z _ { 1 } , { \omega } _ { m } ^ { - 1 } z _ { 2 } )$ ，

2） the groups of automorphisms of $X _ { 3 }$ and $X _ { 4 }$ are infinite.

In this paper we find the groups of automorphisms and some projective models of $X _ { 3 }$ and $X _ { 4 }$ .The main method is to study the geometry of the lattices of algebraic cycles making use of the theory of discrete reflection groups in Lobachevsky spaces [9-13]. This method is also applicable to some other $\mathtt { K 3 }$ surfaces.
