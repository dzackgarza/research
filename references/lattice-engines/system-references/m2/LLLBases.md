# Macaulay2 LLL Lattice Reduction Documentation

Complete reference for the LLLBases package in Macaulay2 - lattice basis reduction functions.

## LLL Basis Reduction

```m2
LLL(m: Matrix | MutableMatrix) -> Matrix | MutableMatrix
```

Compute LLL (Lenstra-Lenstra-Lovász) reduced basis of lattice generated by matrix columns.

**Input:**
- `m` – Matrix or MutableMatrix over ℤ with linearly independent columns

**Output:**
- Matrix or MutableMatrix (preserving type) whose columns form LLL basis

**Optional parameters:**
- `ChangeMatrix => bool` (default: false) – Also return change of basis matrix
- `Strategy => Symbol` (default: "NTL") – Choose algorithm variant
- `Limit => int` (default: ∞) – Computation limit
- `Threshold => Value | null` (default: null) – Algorithm threshold

**Returns:**
- If `ChangeMatrix => false`: LLL reduced matrix
- If `ChangeMatrix => true`: pair {lll_matrix, change_of_basis_matrix}

**Example:**
```m2
m1 = map(ZZ^10, ZZ^10, (j,i) -> (i+1)^3 * (j+1)^2 + i + j + 2);
B = LLL(m1);
{B, U} = LLL(m1, ChangeMatrix => true);
```

## BKZ Basis Reduction

```m2
BKZ(m: Matrix | MutableMatrix) -> Matrix | MutableMatrix
```

Compute Block Korkine-Zolotareff reduced basis.

**Input:**
- `m` – Matrix or MutableMatrix over ℤ with linearly independent columns

**Output:**
- Reduced matrix with better orthogonality properties than LLL

---

## Gram Matrix & Orthogonalization

```m2
gramm(v: list[Vector]) -> Matrix
```

Compute Gram matrix of vectors.

**Input:**
- `v` – List of vectors

**Output:**
- Gram matrix G where G[i,j] = ⟨vᵢ, vⱼ⟩

---

## LLL Verification

```m2
isLLL(m: Matrix | MutableMatrix) -> bool
```

Test whether basis satisfies LLL reduction conditions.

**Input:**
- `m` – Matrix over ℤ

**Output:**
- true if columns form an LLL reduced basis, false otherwise

---

## GCD with Multipliers

```m2
gcdLLL(integers: list[int]) -> pair[int, list[int]]
```

Compute GCD of integers and small multiplier coefficients using LLL.

**Input:**
- `integers` – List of integers

**Output:**
- Pair {gcd, multipliers} where multipliers are small and gcd = Σ(multiplier[i] * integers[i])

---

## Kernel LLL

```m2
kernelLLL(m: Matrix) -> Matrix
```

Compute LLL-reduced basis of kernel (nullspace) of integer matrix.

**Input:**
- `m` – Matrix over ℤ

**Output:**
- Matrix whose columns form LLL basis of ker(m) ∩ ℤⁿ

---

## Hermite Normal Form

```m2
hermite(m: Matrix) -> Matrix
```

Compute Hermite Normal Form of integer matrix.

**Input:**
- `m` – Matrix over ℤ

**Output:**
- Upper triangular Hermite normal form

## Reference

**Package:** LLLBases - Lenstra-Lenstra-Lovász bases

**Version:** 1.1 (July 7, 2005)

**Author:** Michael E. Stillman (Cornell University)

**Implementation:**
- Main LLL algorithm in Macaulay2 engine
- Block algorithms via Victor Shoup's NTL (Number Theory Library)
- Some support routines at top level

**Basis of work:** H. Cohen et al., *Computational Algebraic Number Theory*

**Documentation:** https://macaulay2.com/doc/Macaulay2/share/doc/Macaulay2/LLLBases/html/index.html

**Related packages:**
- Binomials – lattice basis ideals
- LatticePolytopes – lattice polytope computations
