# PARI/GP Lattice Functions Documentation

Complete reference for lattice reduction and vector enumeration functions in PARI/GP.

**Base ring constraints (per official docs):** qflll works with ℤ or ℚ (exact/rational/float entries). Functions mathnf/mathnfmod specifically require base ring ℤ. SVP/CVP (qfminim, qfcvp) require positive-definite forms.

## LLL Reduction

```gp
qflll(x, {flag = 0}) -> Matrix | [Matrix, Matrix]
```

LLL algorithm applied to matrix columns. Returns unimodular transformation matrix T such that x·T is LLL-reduced basis.

**Parameters:**
- `x` – Matrix (columns = lattice vectors)
- `flag` – Algorithm variant:
  - 0 (default): Auto-rescale, use FLATTER algorithm
  - 1: Use classic fplll (disable FLATTER)
  - 2: Partial reduction (Montgomery), faster for knapsack-style
  - 3: In-place reduction (modifies x, returns x·T)

**Output:**
- flag ≤ 1: Transformation matrix T
- flag = 2: Partially reduced basis

**Note:** Default parameters δ = 0.99, η = 0.51

**Example:**
```gp
M = matrix(3, 3, i, j, random(100));
T = qflll(M);
B = M * T;  \\ LLL-reduced basis
```

---

```gp
qflllgram(G, {flag = 0}) -> Matrix
```

LLL reduction of Gram matrix. Same as `qflll()` but input is G = x*x~ instead of coordinates.

**Parameters:**
- `G` – Square symmetric matrix (Gram matrix)
- `flag` – Same as `qflll()`

**Output:**
- Unimodular transformation matrix T

## Linear Dependence

```gp
lindep(v, {flag = 0}) -> Vector
```

Find small nontrivial integral linear combination between components.

**Parameters:**
- `v` – Vector (real/complex/p-adic entries or matrix)
- `flag` – Precision control:
  - 0: Auto-choose accuracy
  - > 0: Use flag decimal digits precision

**Output:**
- Dependency vector, or empty if none found

**Works for:**
- Real/complex floating-point vectors (LLL-based)
- p-adic vectors (LLL on dual lattice)
- Matrices (kernel vector)
- Polynomials/power series (relation with base field coefficients)

## Vector Search & Enumeration

```gp
qfminim(x, {B}, {m}, {flag = 0}) -> [int, float, Matrix]
```

Find all minimal vectors of positive definite form x with ‖v‖² ≤ B using Fincke-Pohst enumeration.

**Parameters:**
- `x` – Square symmetric positive definite matrix
- `B` – Bound (omit/≤0 for closest to origin)
- `m` – Max vectors to store (omit for unlimited)
- `flag` – Output format:
  - 0 (default): [N, M, V] where N = count, M = max distance, V = vectors
  - 1: [M, v] single vector
  - 2: Like 0 but different structure
  - 3: Return only norms

**Output:**
- Enumerated minimal vectors and count

**Example:**
```gp
G = [4, 1; 1, 4];  \\ Gram matrix
result = qfminim(G);
```

---

```gp
qfcvp(x, t, {B}, {m}, {flag = 0}) -> [int, float, Matrix] | [float, Vector] | []
```

Closest Vector Problem: find lattice vectors closest to target t.

**Parameters:**
- `x` – Positive definite Gram/coordinate matrix
- `t` – Target vector
- `B` – Distance bound (omit/≤0 for closest)
- `m` – Max vectors to return
- `flag` – Output:
  - 0 (default): [N, M, V] (count, max distance, vectors)
  - 1: [M, v] (distance, single vector)

**Output:**
- Closest vectors within bound

**Example:**
```gp
G = [2, 0; 0, 2];
target = [0.5, 0.7];
closest = qfcvp(G, target);
```

## Quadratic Form Properties

```gp
qfauto(G, {fl}) -> [int, Vector]
```

Automorphism group of positive definite quadratic form.

**Parameters:**
- `G` – Square symmetric matrix (Gram matrix)
- `fl` – Algorithm variant (computation level)

**Output:**
- [order, generators] where generators are automorphisms

**Example:**
```gp
G = [2, 1; 1, 2];
[order, gens] = qfauto(G);
```

---

```gp
qfisom(G, H, {fl}, {grp}) -> Matrix | []
```

Test isomorphism of positive definite forms G and H.

**Parameters:**
- `G` – Gram matrix
- `H` – Gram matrix
- `fl` – Algorithm control
- `grp` – Automorphism group of H (optional, speeds up)

**Output:**
- Isometry matrix S where G = ~S * H * S (or [] if not isomorphic)

## Hermite & Smith Normal Forms

```gp
mathnf(M, {flag = 0}) -> Matrix | [Matrix, Matrix] | [Matrix, Matrix, Matrix]
```

Hermite Normal Form of integer matrix.

**Parameters:**
- `M` – Integer matrix
- `flag` – Algorithm and output:
  - 0, 1: HNF only (naive)
  - 4: [H, U] with LLL optimization (poly-time, slow)
  - 5: [H, U, P] permutation variant (faster)

**Output:**
- Hermite normal form (upper triangular)
- Optional: transformation matrices

---

```gp
matkerint(x, {flag = 0}) -> Matrix
```

LLL-reduced basis of integer matrix kernel (nullspace).

**Parameters:**
- `x` – Rational matrix

**Output:**
- Columns form LLL-reduced nullspace basis

## Matrix Operations

```gp
matdetint(B) -> Integer
```

Determinant of lattice generated by matrix columns (via Gauss-Bareiss).

**Parameters:**
- `B` – m × n integer matrix

**Output:**
- |det(B)| if square; √det(B~B) if rectangular with maximal rank

---

```gp
bestapprnf(V, T, {rootT}) -> Vector
```

Best approximation in number field.

**Parameters:**
- `V` – Target vector
- `T` – Order/number field definition
- `rootT` – Root element (optional)

**Output:**
- Approximating element with small coefficients

Bilinear form evaluation: ⟨X, GY⟩.

**Parameters:**

## Reference

**System:** PARI/GP 2.13+

**Source:** https://pari.math.u-bordeaux.fr/dochtml/html/Vectors__matrices__linear_algebra_and_sets.html

**Implementation Details:**
- LLL uses FLATTER algorithm (Heninger-Ryan) by default
- Enumeration uses Fincke-Pohst with optional pruning
- Gram matrix computations use Gram-Schmidt with variable precision
- Positive-definite forms required for SVP/CVP

- Lenstra-Lenstra-Lovász reduction
- Fincke-Pohst enumeration
- Plesken-Souvignier automorphism algorithm
