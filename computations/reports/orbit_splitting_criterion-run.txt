Part 2.  B = I_{2,9} and T_Co = B(2)
  Gram diag(1, 1, -1, ..., -1): rank 11, sign count -7, |det| = 1
  e = b_1 + b_3: square 0, primitive True
  v = b_2: square 1, orthogonal to e: True, q(v) = 1/2 > 0
  s_v integral and orthogonal: True; det = -1
  s_v = identity modulo 2B, so s_v lies in the discriminant kernel K
  s_v fixes e, hence the line it spans
  by prop:period-spinor-character's reflection rule, q(v) > 0 gives chi_per(s_v) = -1
  => K contains a component-reversing element, so K != Gamma_Co and [K : Gamma_Co] = 2

Conclusion.  K != Gamma_Co as groups ([K : Gamma_Co] = 2), while by Part 1 K and Gamma_Co have
the SAME orbits on primitive isotropic vectors and lines.  Group equality fails; partition
equality holds, and holds for a reason the index does not give: the stabilizer of every line
carries a component-reversing kernel element (the reflection in a unit vector orthogonal to it).

Part 3.  the plane invariant, and how many values it can take
  For a primitive isotropic plane J, the Gamma_Co-invariant is the image of J in
  T_Co/2T_Co = B/2B = A_{T_Co}, a 2-dimensional totally isotropic subspace; the ISOMETRY TYPE of
  that subspace is (Z/2)^2 with zero pairing for every plane, by thm:plane-transitivity-tco, so the
  type carries no information and only the subspace can separate Gamma_Co-orbits.
  isotropic classes of A_{T_Co}: 528, of them 527 nonzero   (528 and 527 are the established counts)
  2-dimensional totally isotropic subspaces of A_{T_Co}: 23715
  so the invariant of a plane is a point of a set of that size: it is not constant, and it is
  the only isometry-noninvariant datum attached to a plane that this construction gives.
